## อ่านตัวเลขนี้ยังไงให้ถูก

- **CPU คือตัวเลขที่ตรงกับการใช้งานจริงที่สุด** — `webapp/.venv` ติดตั้ง torch แบบ CPU-only
  (`2.13.0+cpu`) และแผนการ deploy ที่ตัดสินใจไว้คือโฮสต์แบบ CPU-only เพราะงานสกัดเฟรม/กำกับ/ส่งออก
  ไม่ได้ประโยชน์จาก GPU
- ตัวเลข GPU มาจาก `D:\ml\ssid-gpu` (torch `2.13.0+cu126`) ซึ่งเป็นสภาพแวดล้อมที่ใช้ฝึกโมเดล
- **เวลาโหลดโมเดล ~8 วินาที จ่ายครั้งเดียว** ไม่ใช่ทุกเฟรม — `server.py` แคช detector ไว้
  (`_assist_cache_detector`) จึงเกิดเฉพาะการเรียกครั้งแรกของแต่ละชุดค่าโมเดล
- **ยังไม่ได้วัด**: เวลาแบบ end-to-end ที่รวม HTTP + การเขียน `state.json` · การทำงานพร้อมกันหลายคำขอ ·
  เครื่องระดับโฮสต์จริง (ตัวเลขนี้มาจากโน้ตบุ๊กเครื่องพัฒนา) — **อย่าอ้างเกินสามข้อนี้**
- จำนวนกล่องต่างกันเล็กน้อยระหว่าง CPU กับ GPU (9.5 vs 9.0) เป็นผลจากความต่างระดับทศนิยม
  ของการคำนวณคนละอุปกรณ์ ไม่ใช่โมเดลคนละตัว
