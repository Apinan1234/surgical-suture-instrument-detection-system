ขอความช่วยเหลือตรวจสอบ · ส.ค. 2569

เว็บแอปกำกับข้อมูลสำหรับระบบตรวจจับอุปกรณ์การเย็บแผล

เครื่องมือที่ใช้ผลิตชุดข้อมูลให้แบบจำลองตรวจจับวัตถุ — สกัดเฟรมจากวิดีโอ กำกับกรอบ ให้ AI ช่วยเสนอกรอบ แล้วส่งออกเป็นชุดข้อมูลรูปแบบ YOLO หน้านี้รวมทุกหน้าจอพร้อมคำถามที่อยากให้ช่วยดู

9 หน้าจอ2,726 เฟรม21,127 กล่อง FastAPI + JavaScript ล้วนYOLO11n · 5 คลาส

อยากให้ช่วยดูอะไร

  • ลำดับการใช้งานเข้าใจง่ายไหม — คนที่เพิ่งเปิดครั้งแรกจะรู้ไหมว่าต้องเริ่มจากแท็บไหน
  • คำบนปุ่มและป้ายสื่อความถูกต้องไหม โดยเฉพาะคำที่ตัดสินใจยาก เช่น Confirm All กับ Reject All
  • จุดที่น่าจะพลาดง่าย — มีปุ่มไหนที่กดผิดแล้วเสียงานไหม และมันเตือนพอหรือยัง
  • มีบั๊กหนึ่งตัวที่รู้อยู่แล้ว อยู่ในหน้าสุดท้าย ลองหาดูก่อนอ่านคำอธิบายก็ได้
1

หน้าเข้าสู่ระบบ

ทุก endpoint ถูกปิดด้วย middleware แบบ deny-by-default ต้องล็อกอินก่อนจึงเรียก API ใด ๆ ได้

จุดที่อยากให้ช่วยดู

เว็บนี้เป็น HTTP ไม่ใช่ HTTPS จึงตั้งใจให้รันบนเครื่องตัวเองเท่านั้น ยังไม่เหมาะกับการเปิดออกอินเทอร์เน็ต

2

แท็บ Extract — ตั้งค่าการสกัดเฟรม

เลือกวิดีโอแล้วกำหนดโหมดสกัด: Adaptive (กำหนดจำนวนเฟรมเป้าหมาย), Fixed Interval หรือ All Frames ตัดช่วงเวลาได้ และมีตัวกรองภาพซ้ำ/ภาพเบลอ

จุดที่อยากให้ช่วยดู

โหมด Adaptive กับ Fixed Interval ต่างกันชัดพอไหม ค่าเริ่มต้น 30 เฟรมเหมาะสมหรือเปล่า

3

แท็บ Detect — เลือกโมเดล

รายการโมเดลแยกเป็นสามกลุ่มและบอกจำนวนคลาสกำกับไว้ท้ายชื่อ — โมเดลของโปรเจกต์ 5 คลาส ส่วนโมเดล พื้นฐาน COCO 80 คลาส

จุดที่อยากให้ช่วยดู

ก่อนหน้านี้รายการนี้เป็นชื่อไฟล์เปล่า ๆ ปนกันหมด และค่าเริ่มต้นคือ yolo11n.pt ทำให้เผลอโหลดโมเดล ที่ตรวจจับ 'คน' แทนเครื่องมือผ่าตัด ตอนนี้แยกออกแล้วและเลือกโมเดลของโปรเจกต์ให้อัตโนมัติ

4

โหลดโมเดลสำเร็จ

ป้ายสถานะไล่ชื่อคลาสที่โมเดลรู้จักครบ: finger, forcep, needle, needle_holder, wound

จุดที่อยากให้ช่วยดู

ป้ายนี้คือวิธีตรวจว่าโหลดถูกตัวก่อนเสียเวลารันทั้งชุด — ถ้าเห็นชื่อคลาสแปลก ๆ แปลว่าเลือกผิด

5

แท็บ Annotate — หน้าจอหลัก

ซ้ายคือแถบเฟรม 2,726 เฟรม กลางคือผืนวาด ขวาคือรายการกล่องพร้อมค่าความเชื่อมั่นและตัวเลือก occluded / truncated · ปุ่ม Confirm All / Reject All ใช้รับหรือทิ้งข้อเสนอจาก AI ทั้งเฟรม

จุดที่อยากให้ช่วยดู

กล่องเส้นประคือข้อเสนอจาก AI ที่ยังไม่ยืนยัน ส่วนเส้นทึบคือที่ยืนยันแล้ว — แยกออกจากกันชัดพอไหม

6

เครื่องมือกำกับข้อมูล 4 แบบ

Select / Draw (กรอบ) / Polygon (รูปหลายเหลี่ยม) / Keypoint (จุด) เลือกได้จากแถบบน และมี Copy from previous frame กับ Interpolate สำหรับเฟรมต่อเนื่อง

จุดที่อยากให้ช่วยดู

ปุ่มเครื่องมือที่กำลังใช้อยู่เด่นพอไหม สลับเครื่องมือแล้วเข้าใจทันทีหรือเปล่าว่าอยู่โหมดไหน

7

แท็บ Export — รูปแบบและสถานะชุดข้อมูล

เลือกส่งออกได้สามแบบ: Detect (กรอบ), Segment (polygon) และ Pose (keypoint) พร้อมป้ายสรุปจำนวนเฟรม จำนวนคลาส และจำนวนที่ยังไม่รีวิว

จุดที่อยากให้ช่วยดู

ป้าย 'Unreviewed: 2725' เตือนได้ดีพอไหมว่ากำลังจะส่งออกข้อมูลที่ยังไม่ได้ตรวจ

8

แบ่งชุดข้อมูลและเพิ่มพูนข้อมูล

กำหนดสัดส่วน Train / Val / Test ด้วยแถบเลื่อน ปรับขนาดภาพ และเลือกเทคนิค augmentation

จุดที่อยากให้ช่วยดู

ค่าเริ่มต้น 70/20/10 เหมาะกับชุดข้อมูลขนาดนี้ไหม และหมายเหตุเรื่องต้องติดตั้ง albumentations เพิ่มเองชัดเจนพอหรือเปล่า
