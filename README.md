# Video Frame Extractor 🎬

แอปพลิเคชัน GUI สำหรับตัดเฟรมภาพจากวิดีโอ (Video Frame Sampler & Similarity Filter) เขียนด้วย Python (Tkinter + OpenCV) 

แอปนี้มีความสามารถในการแยกเฟรมภาพจากไฟล์วิดีโอออกมาเป็นไฟล์รูปภาพ พร้อมด้วยระบบคัดกรองภาพที่ซ้ำหรือเบลอออกไปโดยอัตโนมัติ ช่วยลดจำนวนรูปภาพที่ไม่จำเป็นและประหยัดเวลาในการคัดรูป

## 🌟 ฟีเจอร์หลัก (Features)

*   **GUI ใช้งานง่าย**: สร้างด้วย Tkinter ไม่ต้องพิมพ์คำสั่งใน Command Line
*   **รองรับวิดีโอหลายไฟล์**: สามารถเพิ่มวิดีโอเข้าไปทำคิวรันพร้อมกันได้ทีละหลายๆ ไฟล์
*   **การตัดเฟรม 2 โหมด**:
    *   **Fixed Interval**: กำหนดให้ตัดทุกๆ `X` วินาที
    *   **Adaptive (Target)**: ระบุจำนวนภาพที่ต้องการจากวิดีโอ แล้วระบบจะคำนวณหาระยะเวลาให้เอง
*   **ระบบกรองภาพซ้ำ (Similarity Filter)**: ป้องกันไม่ให้เซฟภาพที่ซ้ายหรือเหมือนกันเกินไป
    *   *Motion IoU*: วิเคราะห์ตำแหน่งการเคลื่อนไหว (เหมาะสำหรับวิดีโอที่มีพื้นหลังนิ่ง เช่น วิดีโอผ่าตัด/เย็บแผล)
    *   *Frame Diff*: ตรวจจับความต่างของพิกเซลตรงๆ
    *   *pHash*: เปรียบเทียบโครงสร้างภาพรวม (Perceptual Hashing)
*   **ระบบกรองภาพเบลอ (Blur Filter)**: ตรวจจับภาพเบลอด้วย Laplacian Variance หากภาพเบลอเกินไปจะทำการข้ามและหาเฟรมถัดไปแทน
*   **Slot Fallback**: หากภาพในจังหวะที่กำหนดใช้ไม่ได้ (เบลอ/ซ้ำ) ระบบจะพยายามขยับเฟรมถัดไปเพื่อหาภาพที่ดีที่สุดให้แทน

## 🛠️ การติดตั้ง (Installation)

1. ต้องมี Python ติดตั้งอยู่ในเครื่อง (แนะนำ 3.8 ขึ้นไป)
2. ติดตั้ง Library ที่จำเป็นผ่าน `pip`:

```bash
pip install -r requirements.txt
```

## 🚀 วิธีใช้งาน (Usage)

รันคำสั่งต่อไปนี้ในโฟลเดอร์โปรเจกต์:

```bash
python frame_extractor.py
```

เมื่อหน้าต่างโปรแกรมเปิดขึ้นมา:
1. กดปุ่ม **➕ เพิ่มวิดีโอ** เพื่อเลือกไฟล์วิดีโอที่ต้องการ
2. ระบุโฟลเดอร์ปลายทางที่ **📁 โฟลเดอร์ Output**
3. ตั้งค่าโหมดการตัด, ระบบคัดกรอง และระบบจัดการภาพเบลอตามต้องการ
4. กดปุ่ม **▶ เริ่มทำงาน**

## 📦 ไลบรารีที่ใช้งาน

*   `opencv-python`: สำหรับอ่านวิดีโอและจัดการรูปภาพ
*   `imagehash`: สำหรับอัลกอริทึม pHash
*   `Pillow`: จัดการภาพและ UI
*   `numpy`: ประมวลผลเมทริกซ์และอาเรย์ของภาพ
*   `tqdm`: (เผื่อใช้งานแบบ CLI หรือแสดงผลในเบื้องหลัง)
*   `tkinter` (มาพร้อมกับ Python อยู่แล้ว)
