## ส่วน B — เช็คลิสต์เนื้อหาตามโครงสไลด์ (71 แผ่น หลังเพิ่ม N7-N9 · 15 ส.ค. 2569)

ติ๊กระหว่างซ้อมว่าพูดครบทุกแผ่นและใจความหลักไม่ตก

**บทที่ 1 — เปิดเรื่อง (สไลด์ 1-5)** ☐
ปก → ปัญหา/ที่มา → วัตถุประสงค์ → ขอบเขต → ภาพรวมสิ่งที่ส่งมอบ (2,726 เฟรม/21,127 กล่อง)

**บทที่ 2 — ภาพรวมระบบ (สไลด์ 6-8, N1, N2, N7)** ☐
กระบวนการเป็นวงจร → สถาปัตยกรรม → **N7** เครื่องมือและเทคโนโลยีที่ใช้ → ขอบเขตระบบ (context) →
**N1** การเก็บความต้องการ → **N2** การออกแบบ UI/UX

**บทที่ 3 — ข้อมูล (สไลด์ 9-14)** ☐
การเก็บ/สกัดข้อมูล → 9 คลาส → ชุดข้อมูลสุดท้าย (2,190 ภาพ) → ความไม่สมดุลของคลาส
(⚠️ พูดเรื่อง Stitch Scissors 16 กล่องตรงนี้เลย — กติกา ❷) → ข้อบกพร่องป้ายกำกับ (เงียบ ไม่มี error) →
ผังงานทำความสะอาด

**บทที่ 4 — แบบจำลอง (สไลด์ 15-18, N8, N9)** ☐
สถาปัตยกรรม YOLO11 (ชั้น P3 = วัตถุเล็ก · backbone/neck/head · loss 3 ส่วน · 182 ชั้น/2.59M
พารามิเตอร์ · 6.5→14.8 GFLOPs เมื่อขึ้น 960) → ผังงานการฝึก (`best.pt` ≠ `last.pt`) →
**N8** การฝึกโมเดล: การตั้งค่าและฮาร์ดแวร์ → การออกแบบ A/B (ตัวแปรต่างกันต้อง = 1) →
ผังงานการอนุมาน (กรองสองชั้น) → **N9** ปัญหาที่เจอระหว่างพัฒนาแบบจำลอง (4 เรื่อง: resume การฝึก ·
imgsz ที่เคยเข้าใจผิด · ป้ายกำกับปนกัน · pagefile limit)

**บทที่ 5 — ผลการทดลอง (สไลด์ 19-27)** ☐
A/B augmentation ชนะขาด → หลักฐาน overfitting → เทียบสี่รอบ (⚠️ **ต้องพูดตรง ๆ ว่า mAP50 ของ 640
กับ 960 เท่ากัน — กติกา ❶**) → ผลรายคลาสเทียบสี่รอบ → แบบจำลองที่ดีที่สุด (mAP50 0.7160, หมายเหตุ
ตัด Stitch Scissors เหลือ 0.6990) → ตารางรายคลาส (needle อ่อนสุด 0.3603) → confusion matrix
(needle พลาดเป็น background ไม่ใช่สับสนคลาสอื่น) → PR/F1 curve (conf จริง = 0.25) →
**เจาะลึก needle** (วัด → ตั้งสมมติฐาน → ทดสอบ imgsz 640→960)

**บทที่ 6 — เว็บแอป (สไลด์ 28-38, N3, N4, N5)** ☐
ทำไมต้องมีเว็บแอป → use case → DFD → ผังงานสกัดเฟรม → ลำดับสกัดเฟรม ⚠️ → ลำดับ Label Assist ⚠️ →
วงจรกำกับข้อมูล ⚠️ → สถานะงาน → สถานะเฟรม → โครงสร้างข้อมูล → ภาพหน้าจอจริง 6 ภาพ →
**N3** ฟังก์ชันครบทั้งระบบ (39 endpoint) → **N4** deployment → **N5** ประสิทธิภาพ (ดูหัวข้อ ⚠️⚠️ ด้านบน)

**บทที่ 7 — ปิด (สไลด์ 39-41, N6)** ☐
ข้อจำกัดของงาน (พูดตรง ๆ) → **N6** ผลสำเร็จตามแผน (104 commit) → งานระยะถัดไป → สรุป 3 ข้อความ

**Backup 12 แผ่น (B1-B12)** ☐ — ไม่ต้องพูดถ้าไม่ถูกถาม แต่เปิดหาได้ทันที: hyperparameter เต็ม ·
เหตุผลยังเลือก 960 ทั้งที่ mAP50 เท่ากัน · Stitch Scissors 16 กล่อง · ขนาดกล่องรายคลาส · ผล test
เต็ม · loss แยกสามตัว · LR schedule · ตัวอย่างที่โมเดลทำผิด · เรื่อง imgsz ที่เคยสรุปผิด (กติกา ❽) ·
label defect เต็ม · สเปกเครื่องเทรน · deployment diagram
