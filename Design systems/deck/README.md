# deck/ — ตัวสร้างสไลด์ .pptx

ไฟล์ที่ได้: **`ระบบตรวจจับอุปกรณ์การเย็บแผล-สอบโครงงาน2.pptx`** · 71 สไลด์ · 16:9 · ~5.3 MB

## แก้สไลด์ยังไง

**ถ้าจะแก้เล็กน้อย** (ย้ายกล่อง เปลี่ยนคำ ลบสไลด์ที่ไม่เอา) — เปิดใน PowerPoint แล้วแก้ได้เลย
ทุกอย่างเป็นวัตถุจริง ไม่ใช่รูปแปะ · **การตัดสไลด์ให้เหลือเท่าที่จะพูดจริง ให้ทำใน PowerPoint**

**ถ้าจะแก้เนื้อหาแล้วอยากให้ generate ใหม่ได้เรื่อย ๆ** — แก้ `content.py` แล้วรัน

```
python build_deck.py       # สร้างไฟล์ .pptx ใหม่ทับของเดิม
python verify_deck.py      # ตรวจตัวเลขกับไฟล์ต้นทาง + ไล่กติกา ❶-❾
```

> `build_deck.py` เขียนทับไฟล์ .pptx ทุกครั้ง — **ถ้าแก้ใน PowerPoint ไปแล้ว ให้ Save As ชื่ออื่นก่อนรันใหม่**

## ไฟล์ในโฟลเดอร์นี้

| ไฟล์ | หน้าที่ |
|---|---|
| `theme.py` | design system — สี 7 บทบาท ฟอนต์ สเกลตัวอักษร เรขาคณิตของสไลด์ |
| `layouts.py` | archetype 10 แบบ (ปก · คั่นบท · bullet · diagram · diagram ทรงสูง · แถวตัวเลข · เทียบซ้ายขวา · ตัวเลขเต็มจอ · ตาราง · กริดภาพ) |
| `content.py` | **เนื้อหาทุกสไลด์** — ไฟล์ที่จะแก้บ่อยที่สุด |
| `build_deck.py` | ประกอบทั้งหมดเป็น .pptx + ยัด theme ลงไฟล์ + ตรวจว่าไม่มีวัตถุล้นขอบ |
| `verify_deck.py` | ตรวจ .pptx ที่สร้างแล้ว: ตัวเลข 36 ค่าเทียบไฟล์ต้นทาง และกติกาความถูกต้อง |

ต้องมี `python-pptx` (`pip install python-pptx`) — ติดตั้งแล้วบนเครื่องนี้

## design system เดินทางไปกับไฟล์แค่ไหน

**ที่ไปด้วย:** สีทั้ง 7 บทบาทถูกเขียนลง theme ของไฟล์ — เปิด PowerPoint แล้วกดเลือกสี จะเห็นชุดสีนี้
ในแถวบนสุด (Theme Colors) · ฟอนต์ธีมเป็น **Leelawadee UI** ทั้ง latin/ea/cs กล่องข้อความที่เพิ่มเอง
ทีหลังจึงได้ฟอนต์เดียวกันโดยไม่ต้องตั้งเอง

**ที่ไม่ได้ทำ:** ยังไม่ได้สร้าง slide layout แยกตาม archetype ใน master — กด "New Slide" จะยังได้
layout มาตรฐานของ PowerPoint **วิธีเพิ่มสไลด์ให้หน้าตาเหมือนกัน คือคลิกขวาสไลด์ที่ชอบ → Duplicate Slide**
แล้วแก้ข้อความ

## กติกาที่ verify_deck.py บังคับให้

1. ตัวเลขทศนิยมทุกค่าที่อ้าง ต้องหาเจอในไฟล์ผลจริงใน `../assets/`
2. ห้ามมีคำว่า FPS / มิลลิวินาที / เฟรมต่อวินาที (กติกา ❹ — ยังไม่เคยวัด)
3. ห้ามอ้างเลข 0.608 (กติกา ❸ — ทำซ้ำไม่ได้แล้ว)
4. ทุกสไลด์ที่พูดถึง 0.7160 ต้องมีหมายเหตุ Stitch Scissors ในแผ่นเดียวกัน (กติกา ❷)
5. ทุกสไลด์ที่มีตัวเลข ต้องมีบรรทัด "ที่มา:" มุมล่างซ้าย

**ถ้าแก้ `content.py` แล้ว ให้รัน `verify_deck.py` ทุกครั้ง** — มันจับได้จริง ตอนสร้างรอบแรกมันจับ
สไลด์ที่อ้าง 0.7160 โดยลืมหมายเหตุไป 3 แผ่น
