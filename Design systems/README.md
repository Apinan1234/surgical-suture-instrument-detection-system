# Design systems — แพ็กวัตถุดิบสำหรับทำสไลด์นำเสนอโครงงาน

โฟลเดอร์นี้รวม **ทุกอย่างที่ต้องใช้ทำสไลด์สอบโครงงาน** ไว้ที่เดียว
ระบบตรวจจับอุปกรณ์การเย็บแผลด้วยปัญญาประดิษฐ์ · สอบ ~1 ชั่วโมง · ภาษาไทย

## อ่านตามลำดับนี้

| ลำดับ | ไฟล์ | คืออะไร |
|---|---|---|
| 1 | **`SLIDE-BRIEF.md`** | **ไฟล์หลัก — ส่งให้ Claude Design ทั้งไฟล์ได้เลย** มีกติกาความถูกต้อง 8 ข้อ, โครงสไลด์ 41 สไลด์ + backup 12, และ design system (สี ฟอนต์ archetype) |
| 2 | `ASSET-INDEX.md` | ไฟล์ทุกตัวในแพ็กว่าแสดงอะไร ใช้กับสไลด์ไหน และรองรับข้ออ้างไหน |
| 3 | `deck/README.md` | **สไลด์สร้างเสร็จแล้ว** วิธีแก้และ generate ใหม่ |

## ตัวเลขที่ต้องจำ

| | val | test |
|---|---:|---:|
| mAP50 | **0.7160** | 0.7015 |
| mAP50-95 | 0.4532 | 0.4348 |
| precision | 0.7335 | 0.7331 |
| recall | 0.7173 | 0.6926 |

**needle** mAP50 0.3603 — คลาสที่อ่อนที่สุด · **ตัด Stitch Scissors (16 กล่อง) แล้วเฉลี่ย 8 คลาส = 0.6990**

การทดลอง A/B: mAP50 0.5746 → 0.6559 เมื่อเปิด augmentation

**ความเร็ว** (วัด 14 ส.ค. 2569): อนุมาน **139.8 ms/เฟรม บน CPU** (5.59 เฟรม/วินาที) ·
**44.7 ms บน GPU** (13.41 เฟรม/วินาที) — CPU คือตัวเลขที่ใช้เล่า เพราะเว็บแอปรันบน torch แบบ CPU-only

> ⚠️ **mAP50 ของ 640 (0.7163) กับ 960 (0.7160) เท่ากัน** — สิ่งที่ 960 ได้เพิ่มคือ mAP50-95
> และ recall ของ needle **ห้ามเขียนสไลด์ว่าเพิ่มความละเอียดแล้วคะแนนรวมดีขึ้น**
> เหตุผลเต็มอยู่ในกติกาข้อ ❶ ของ `SLIDE-BRIEF.md`

## หมายเหตุ

- ทุกไฟล์เป็น **สำเนา** ตรวจแล้วว่าตรงกับต้นฉบับทุกไบต์ ต้นฉบับยังอยู่ที่ `05_reports/` และ
  `01_frame-extractor-tool/results_*/` — ถ้าต้นฉบับอัปเดต แพ็กนี้ไม่อัปเดตตาม ต้องคัดลอกใหม่
- ชื่อโฟลเดอร์มีเว้นวรรค เวลาเขียนสคริปต์ต้องใส่เครื่องหมายคำพูดครอบ path
- `ASSET-INDEX.md` หัวข้อท้ายสุดระบุไว้ว่า **อะไรถูกตัดออกจากแพ็กและเพราะอะไร** อ่านก่อนถ้าสงสัยว่า
  ทำไมไฟล์บางตัวไม่อยู่ในนี้

## งานที่ยังไม่ได้ทำ (ตั้งใจ)

แพ็กนี้เป็นวัตถุดิบ ยังไม่ใช่สไลด์ · หลังทำสไลด์เสร็จยังเหลืออีกสองอย่างที่ผู้ใช้ระบุไว้แล้ว —
**บทพูดประกอบสไลด์** และ **ชุดคำถามซ้อมสำหรับตอบอาจารย์** ซึ่ง `SLIDE-BRIEF.md` เขียนโครงไว้รองรับแล้ว
(หนึ่งสไลด์ = หนึ่งข้อความ + หลักฐานที่อ้างได้ + ที่มาของตัวเลข)
